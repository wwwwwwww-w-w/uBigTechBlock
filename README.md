Assume these filters only work on English versions of pages, as most of these rules depend on displayed page texts.
I will not support other languages in this repo nor accept any pull requests, however feel free to fork uBigtechBlock and create your own non-English version.

# Installation
To install any of these filters, you can either download the .txt file and open it with the "Import and Append" button under uBlock Origin dashboard > My Filters, or you can simply copy-paste the contents of the .txt file into the filter list in the same location.

These custom filters were written at 1920x1080 resolution in LibreWolf running uBlock Origin 1.76.0. 
If you encounter issues in your setup, or have requests for other Big Tech™ site cleanup, open an issue.
